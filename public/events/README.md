# Panduan Menaruh Foto Event

Semua folder event resmi telah dibuat di folder ini: `public/events/`

### Struktur Folder Event:
1. `public/events/appmbgi-national-summit-2026/`
2. `public/events/team-building-bp-tapera-2025/`

8. `public/events/empowering-women-in-politics/`
9. `public/events/book-launching-restorative-justice/`

### Cara Menaruh Foto:
- Anda cukup meng-copy foto ke dalam folder event yang sesuai.
- Gunakan nama file standar:
  - `cover.jpg` (untuk foto utama card event)
  - `photo-1.jpg`, `photo-2.jpg`, `photo-3.jpg`, dst. (untuk galeri foto di halaman detail event)
- Format gambar yang didukung: `.jpg`, `.jpeg`, `.png`, `.webp`.
