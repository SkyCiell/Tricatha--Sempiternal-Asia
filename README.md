## 🏛️ About Tricatha Sempiternal Asia

**Tricatha Sempiternal Asia (TSA)** operates from **The City Tower in Jakarta, Indonesia**. We are an integrated practice building high-stakes solutions across public advocacy, enterprise digital governance systems, broadcast media, and diplomatic summits.

Our digital portal embodies a high-end, editorial, typography-driven visual aesthetic built with modern web technologies, smooth scroll physics, and custom interactive GSAP animations.

---

## 🌟 Key Features & Capabilities

- **Editorial Visual Aesthetics**: Sleek dark navy system (`#071A2B`) paired with high-contrast typography and subtle green (`#42D3A5`) & blue (`#155EEF`) accents.
- **ScrollExpand Hero Narrative**: Immersive full-screen background video (`0805.mp4`) with smooth scroll reveal dynamics.
- **Integrated Capabilities (FlowingMenu)**: Interactive GSAP continuous marquee hover list showcasing core strategic capabilities with embedded local media assets.
- **Selected Works Accordion Showcase**: GSAP-powered interactive 3D media gallery (`AccordionGallery.jsx`) for head-of-state summits and sovereign platforms.
- **Typography-Driven Showcase Modal**: Clean, dashboard-free editorial project case study modal (`ProjectModal.jsx`) displaying key execution highlights, timelines, and measured impact.
- **Lenis Inertial Smooth Scroll**: Seamless, hardware-accelerated inertia scrolling configured across all devices.
- **Deep Linking & Hash Navigation**: Instant deep link URL route synchronization (`/#about`, `/#services`, `/#work`, `/#contact`) without page reloads or 404 errors.

## 💻 Getting Started Locally

### 1. Prerequisites
Ensure you have **Node.js** (v18.0.0 or higher) and **npm** installed.

### 2. Installation
Clone the repository and install dependencies:

```bash
# Clone the repository
git clone https://github.com/SkyCiell/Tricatha--Sempiternal-Asia.git

# Navigate into the project folder
cd Tricatha--Sempiternal-Asia

# Install NPM packages
npm install
```

### 3. Development Server
Run the local development server with Hot Module Replacement (HMR):

```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 📦 Production Build

To build the production-ready static assets:

```bash
# Build production bundle
npm run build

# Preview the build locally
npm run preview
```

The optimized static files will be generated inside the `dist/` directory.
