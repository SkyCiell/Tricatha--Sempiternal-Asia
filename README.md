## Overview

Tricatha Sempiternal Asia (TSA) is an integrated practice headquartered at The City Tower, Jakarta, Indonesia.

The website serves as a digital representation of TSA's operational capabilities, presenting its work across public advocacy, digital governance, broadcast media, and diplomatic summits.

The experience is built around an editorial design direction, combining typography, visual storytelling, interactive media, and motion to create a cohesive digital presence.

## Core Capabilities

| Division | Focus |
|---|---|
| Government Advocacy | Sovereign relations, public policy intelligence, and public-private sector partnerships. |
| GovTech & Systems | Enterprise digital governance, telemetry platforms, and policy intelligence systems. |
| DNA Studio Broadcast | Executive dialogues, podcast production, broadcast environments, and cinematic motion design. |
| Field Activation & Summits | International summit execution, plenary assembly coordination, and experiential installations. |

## Experience & Features

**Immersive Hero**

A full-screen video experience using `0805.mp4`, integrated with scroll-driven transitions and reveal animations.

**Interactive Capabilities**

A GSAP-powered FlowingMenu featuring continuous marquee interactions and supporting visual media.

**Selected Works**

An interactive accordion gallery showcasing selected summit productions and sovereign platforms, powered by `AccordionGallery.jsx`.

**Project Case Studies**

A typography-led project modal presenting execution details, timelines, and project outcomes without unnecessary dashboard-style UI.

**Smooth Scrolling**

Lenis-powered scrolling integrated with the animation system for consistent motion behavior.

**Direct Navigation**

Hash-based navigation supporting direct access to individual sections:

- `/#about`
- `/#services`
- `/#work`
- `/#contact`

## Getting Started

### Requirements

- Node.js 18 or later
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/SkyCiell/Tricatha--Sempiternal-Asia.git
```

Navigate into the project directory:

```bash
cd Tricatha--Sempiternal-Asia
```

Install dependencies:

```bash
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.

## Production

Generate the production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

The generated production assets are available in the `dist/` directory.
